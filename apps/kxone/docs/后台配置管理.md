# 后台配置管理

后台配置接口仅允许 `admin` 角色访问，统一挂在 `/api/admin` 下。

## 系统配置

### 查询配置

```http
GET /api/admin/settings?group=wecom
Authorization: Bearer <admin token>
```

响应：

```json
{
  "settings": [
    {
      "key": "wecom.corp_id",
      "value": "corp_xxx",
      "value_type": "string",
      "group": "wecom",
      "description": "企业 ID",
      "is_sensitive": false
    }
  ]
}
```

敏感配置返回时会脱敏为 `******`。

### 更新配置

```http
PUT /api/admin/settings
Authorization: Bearer <admin token>
Content-Type: application/json
```

```json
{
  "settings": [
    {
      "key": "reminder.dispatch_minutes",
      "value": "3,5,10",
      "value_type": "csv_int",
      "group": "business",
      "description": "待分配提醒分钟",
      "is_sensitive": false
    }
  ]
}
```

当前已接入运行期读取的配置：

| key | 说明 | 生效范围 |
| --- | --- | --- |
| `wecom.corp_id` | 企业 ID | access_token 获取、OAuth、卡片和提醒 |
| `wecom.agent_id` | 企业微信应用 AgentID | 卡片发送、卡片重发、文本提醒 |
| `wecom.secret` | 企业微信应用 Secret | access_token 获取、OAuth |
| `wecom.token` | 回调 Token | 回调 URL 验证、回调消息解密 |
| `wecom.encoding_aes_key` | 回调 EncodingAESKey | 回调 URL 验证、回调消息解密 |
| `reminder.dispatch_minutes` | 待分配提醒分钟，逗号分隔 | 创建线索后的派发提醒 |
| `reminder.claim_minutes` | 待领取提醒分钟，逗号分隔 | 分配、转派后的领取提醒 |
| `card.retry_seconds` | 卡片失败重试秒数，逗号分隔 | 自定义卡片重试延迟 |

企业微信配置会优先读取后台配置，未填写时回退环境变量。access_token 缓存按当前 `corp_id` 隔离，切换企业配置后不会复用旧企业 token。

## 企业微信状态

```http
GET /api/admin/wecom/status
Authorization: Bearer <admin token>
```

返回当前生效的企业微信配置状态。`Secret`、`Token`、`EncodingAESKey` 只返回是否已配置，不返回明文。

## 企业微信诊断

```http
GET /api/admin/wecom/diagnostics?url=https%3A%2F%2Fcrm.example.com%2Fleads
Authorization: Bearer <admin token>
```

诊断内容：

- 必填配置是否完整：`corp_id`、`agent_id`、`secret`、回调 `token`、`encoding_aes_key`、回调地址、可信域名。
- 实际获取 `access_token`。
- 实际生成 JSSDK config，用于确认 `jsapi_ticket` 可获取。

响应中的 `ok` 表示全部检查通过，`checks` 会给出每一项的检查结果和错误信息。

## 用户绑定管理

### 查询绑定

```http
GET /api/admin/user-bindings?status=active&page=1&page_size=20
Authorization: Bearer <admin token>
```

### 新增绑定

```http
POST /api/admin/user-bindings
Authorization: Bearer <admin token>
Content-Type: application/json
```

```json
{
  "crm_user_id": 1001,
  "wecom_userid": "sales_001",
  "employee_name": "销售一",
  "role": "sales",
  "department_id": 0,
  "status": "active"
}
```

### 更新绑定

```http
PUT /api/admin/user-bindings/1
Authorization: Bearer <admin token>
Content-Type: application/json
```

请求体同新增绑定。

## 权限

所有后台配置接口必须携带 JWT，并通过：

```text
RequireRole("admin")
```

主管和销售访问会返回 `403 insufficient_permissions`。
