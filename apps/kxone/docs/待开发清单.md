# 待开发清单

> 历史待办清单：企微 OAuth、自建应用卡片、回调领取及旧生产 dev 描述已不适用于当前 CRM。当前使用账号密码认证；功能、权限和发布以 [CRM现行业务与维护规则](CRM现行业务与维护规则.md) 为准。旧企微条目不纳入本轮启用范围。

更新时间：2026-07-01

## P0：上线前必须闭环

1. 正式企业微信 OAuth 登录闭环
   - 已完成：后端 `/api/auth/wecom/authorize` 发起授权。
   - 已完成：OAuth 回调后保存 `access_token` / `refresh_token` 并跳回原页面。
   - 已完成：401 时优先刷新 token，刷新失败再重新 OAuth。
   - 已完成：生产构建不再自动使用开发 Token 兜底。
   - 待验证：在企业微信客户端内用真实成员完成端到端 OAuth 登录。

2. 企业微信应用入口与卡片跳转联调
   - 企业微信工作台入口指向 `https://kxone.example.com`。
   - 卡片按钮跳转到具体 H5 页面，例如线索详情、跟进页。
   - 在企业微信客户端内验证 JSSDK、OAuth、卡片点击回调完整链路。

3. H5 补齐主管操作入口
   - 已完成：主管/管理员可在 H5 新建线索。
   - 已完成：线索详情页支持手动分配、转派、推荐销售、自动分配。
   - 已完成：列表页增加待分配视图和新建入口。
   - 待增强：销售选择仍为企业微信 UserID 输入，后续接完整员工选择器。

4. 用户绑定与权限真实数据闭环
   - 已完成：用户绑定支持维护企业微信 UserID、CRM 用户 ID、姓名、角色、部门、状态。
   - 已完成：新增主管可访问的活跃销售列表接口 `/api/users/sales`。
   - 已完成：H5 分配/转派弹窗接入销售选择器。
   - 待增强：当前员工目录仍复用用户绑定表，尚未拆出完整 CRM 用户、部门、上下级关系表。

5. 生产环境收口
   - 服务器当前仍为 `SERVER_ENV=dev`。
   - 上线前切为 `prod`，关闭开发 Token。
   - 当前生产数据仍使用 SQLite，正式业务建议迁移 MySQL/PostgreSQL。
   - 已完成：提供 `scripts/backup_sqlite.sh` 备份当前 SQLite 数据库。
   - 已完成：提供 `scripts/deploy_kxone.sh` 脚本化部署。
   - 待完成：切换 `SERVER_ENV=prod` 前，需要先确认真实管理员企业微信账号已绑定。
   - 待增强：正式业务建议迁移 MySQL/PostgreSQL，并做恢复演练。
