# 数字可信度与上下文管理

候选修复；真实模型组合验收完成前不能启用线上 AI 分析。

## 数据与答案

临时快照新增 entity_index/entity_index_history，覆盖每条获准业务记录，包括没有文字内容的行。复合主键为原表名和原主键，实际操作者沿用已审查映射，未知保持未知。默认范围与原表的回收站可见性一致。

内部 measure_record_set 支持 source（完整原表）或 sql（返回 record_type、整数 record_id 的集合），visibility=current/history，group_by=actor_user_id/record_type/business_stage/occurred_date_shanghai/source_channel。同一集合分别产生全局与分组去重事实；去重线索指标不可相加。未知ID、非法类型、范围外身份返回错误，聚合使用同一快照和五秒SQL期限，不经过预览截断。

finalize_answer 接受 markdown、references、conditions。正文 {{token}} 由服务端填入对应的事实或已读取单元格，引用须属于本轮最终选定结果。所有引用必须独立成段，不能在令牌前后重新附加另一指标名称、实体或量词；也可只列 references，由服务端自动附加完整陈述。事实保留真实 record_types；跟进记录数与有历史计划（next_followup_at 非空）的跟进记录数分别计算。普通 SQL 单元格明确标为查询指标，列别名的业务语义仍需独立审查。统计数字、模型数据表和无依据全称、重叠、因果结论经过保守检查；数字扫描不是完整自然语言证明，仍需语义评测。最终纠正最多一次，与选择结果纠正共用，所有调用仍计入原限制。

时间单元格引用可设置 comparison=snapshot；仅支持本轮最终选定且实际读取的 cell，不接受事实引用或其他比较方式。服务端将带 Z 或明确 UTC 偏移的 RFC3339 时间与结果保存的 SnapshotAt 比较，保留纳秒精度并按上海时间展示；YYYY-MM-DD 只比较上海日历日期，同日不推断具体时刻先后。缺失、非法或无时区的时间不猜测。比较结果是查询单元格与快照的关系，不证明预约是否有效、是否到访或是否逾期；scheduled 不代表计划在将来，过去的计划时间也不会自动使预约失效。

正文与标题中的未绑定时间关系经过保守检查，状态描述“未到访”“未到场”不等同于时间尚未到达。时间扫描与数字扫描一样，不是完整自然语言或 SQL 业务语义证明，仍须独立评测筛选范围、额外主张与用户意图。服务端生成的时间核对文字与正式答案一起保存，页面、复制、Excel 和报告复用该产物，不按查看或导出时的当前时间重新计算。

最终纠正仍只有原定的一次机会。遇到未绑定数量或时间关系且原引用可核对时，反馈可附结构化修订提案：保留全部结果、引用（含 comparison）、表格和条件，将完整原解释作为待审核草稿保留，不替模型猜数字或时间主张的归属。提案最大 6 KiB、工具页最大 8 KiB，不能放下时明确拒绝而不截断。模型必须再次调用 finalize_answer；只回复确认不能完成，提案不会自动发布。模型仍须复核是否充分回答原问题。

新 sources 块保存 verification.version=6 与事实或单元格引用，时间比较引用同时保存 comparison。既有 version=5 及更早回答保持原文和原验证元数据，不回溯验证，也不标记为通过时间契约6。SSE 只提前显示进度，正式 message/done 与答案在原有原子事务一起提交；失败、取消和断流草稿不进入正式消息或导出。前端忽略旧服务器重放的 draft delta。

## 模型输入与连续分析

describe_data 默认是目录和必备规则。tables 参数读取指定表字段/枚举/关系/口径，topic=metrics/rules 可按 next_offset 分页；完整业务字典在本地仍保留。模型专用页最多8KiB，保存和导出的结果不缩减。read_result 支持结果行分页或 row/column/text_offset 文本分段，披露未读范围；read_history 只能读取本会话的用户或已完成历史消息。

每次模型请求检查最终UTF-8 JSON字节：48KiB准备收束/新执行段，64KiB硬上限不变。最多主动分段一次，原run、快照、结果ID、账本、8次模型、12次工具、180秒及3元上限保持。新段保留问题、显式条件、执行过的查询与参数、结果目录和选择，不额外调用模型做摘要。历史背景作为引用材料，不假装为供应商原生assistant/tool历史。主备切换使用相同方式；本地容量或供应商上下文拒绝不触发备用重试。

当前DeepSeek原生执行段保留完整推理与工具配对；推理通过本地隐私检查后原样回传，整个供应商响应的正文、原生推理及工具参数都在接纳前检查。命中不能出站的片段时丢弃整个响应及未执行工具，可使用尚未消耗的一次主动分段机会从已核对依据继续；已使用机会或再次命中则安全停止，不编辑或填空供应商推理。已发生调用仍照常结算，不重复成功查询。推理不存入会话、SSE、导出或日志。context_usage只记录各类内容的字节，context_checkpoint只记录段数及结果数。

若被隐私检查拒绝的原生响应仅含单个 finalize_answer，可在原有唯一分段机会中携带本地脱敏的待审核提案；混合工具、推理、未知字段不恢复，必要的未执行工具不能静默丢弃。提案须重新核对当前快照、已读结果/引用及用户原条件，敏感标识或无法安全处理的文本直接拒绝。显式客户身份标签优先于业务词豁免，普通文本误判依然按保守脱敏处理，本机制不意味着启发式识别已没有误判。

仅隔离验收可注入最终校验审计钩子，记录已通过响应隐私检查的类型化提案及校验结果，不保存私有推理或未知字段；生产默认为空。日志披露截断与字节范围，避免将缺失的拒绝正文猜测为已知。供应商结构化 context_exceeded_error 归类为供应商上下文限制，不冒充本地超限或触发备用调用。

ai_runs新增analysis_context_json与error_code，迁移000032只增加Agent元数据。显式条件引用真实用户原文与消息ID；日期、人员、来源、状态及其他范围分别保存，本轮更正只替换相应类别。过多条件或无法确认的引用返回错误，不能静默丢弃。error_code区分context_capacity/provider_context_limit/answer_validation_failed/budget_limit/call_limit/provider_protocol/provider_privacy/snapshot_timeout。

## 业务性能保护

小规格主机上的快照准备按实际工作时间让出 CPU，源数据读取、身份登记、脱敏物化及索引分批均受调度约束；全局同时仅构建一个快照，仍允许两个分析运行。源读取使用同一个只读短事务，十秒子截止时间不延长原运行期限，失败时整轮放弃且释放事务。后续工作只访问临时文件，其 MEMORY journal/OFF synchronous 不改变业务库 WAL 与持久化设置。snapshot_ready 只记录源读取耗时及行数，不含客户内容。

## 验证边界

确定性回归覆盖A08分组3/1但全局3、跨表投影重复、无文字记录、删除范围、伪造身份、事实层级/快照、正文四条与4条、长会话条件纠正、UTF-8文本分段、64KiB边界、分段不重查/不重复计费及未核验草稿不可见。大数据统计继续与10001线索/50001跟进的独立预期对账。

时间回归覆盖上海跨日、同一时刻的不同偏移、纳秒边界、同日日期精度、无时区及非法时间拒绝、未读或弃用结果拒绝，以及到访状态与时间判断的区分。可控模型通过真实 Service 的三次调用覆盖查询、错误时间主张、唯一纠正提案及显式重提交流程，核对 comparison/version=6 持久化且正式消息与 SSE 不含被拒草稿；这属于确定性协议集成验证，不代替真实云模型的语义验收。

真实模型需在冻结版本完成A08/A13/A21各三次、去重变体、完整30题、关键重复、大数据及实际浏览器验收。每次运行完成与语义通过分别判定，额外主张也必须检查；费用是按配置单价估算，未知用量保留预留。
