# 企业微信真实环境配置

## 必填环境变量

复制 `.env.example` 为 `.env`，并填写：

```bash
WECOM_CORP_ID=企业ID
WECOM_AGENT_ID=自建应用 AgentId
WECOM_SECRET=自建应用 Secret
WECOM_TOKEN=回调 Token
WECOM_ENCODING_AES_KEY=回调 EncodingAESKey
WECOM_CALLBACK_URL=https://你的域名/api/wecom/callback
WECOM_TRUSTED_DOMAIN=你的可信域名
JWT_SECRET=生产环境随机长密钥
```

`WECOM_AGENT_ID` 已由企业微信客户端作为默认 AgentID 使用。业务代码里传 `AgentID: 0` 时会回退到该配置。

## 企业微信后台配置

1. 在企业微信后台创建自建应用，记录 `AgentId` 和 `Secret`。
2. 在应用的“网页授权及 JS-SDK”里配置可信域名，对应 `WECOM_TRUSTED_DOMAIN`。
3. 在应用的“接收消息”里配置回调 URL：
   `https://你的域名/api/wecom/callback`
4. 将后台生成或填写的 `Token`、`EncodingAESKey` 同步到环境变量。
5. OAuth 回调地址使用：
   `https://你的域名/api/auth/wecom/callback?code=企业微信返回的 code`

## 用户绑定

OAuth 登录依赖 `crm_wecom_user_bindings` 表。上线前需导入企业微信用户与 CRM 用户的绑定关系，且状态为 `active`。

必填字段：

- `crm_user_id`
- `wecom_userid`
- `employee_name`
- `role`: `manager` / `sales` / `admin`
- `status`: `active`

## JSSDK 状态

H5 已接入企业微信 JSSDK 初始化逻辑，默认请求：

```http
GET /api/wecom/jsapi-config?url=<当前页面 URL，不含 hash>
```

后端会：

1. 使用当前生效的企业微信配置获取 `access_token`。
2. 获取并缓存 `jsapi_ticket`。
3. 按当前页面 URL 生成 `nonceStr`、`timestamp`、`signature`。
4. 返回 H5 `wx.config` 所需配置。

如果页面不在企业微信环境中，H5 会跳过 JSSDK 初始化，不影响普通线索列表、详情、领取和跟进流程。
