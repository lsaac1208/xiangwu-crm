# CRM 界面与交互检查（2026-09-07）

## 范围

本次只处理 CRM。CMS 的探索性源码改动已撤回，不纳入交付或部署。
保留 Vue 3、Vite、Vant 和已有颜色、字体、间距体系，不更换框架。

检查对象：登录、线索列表、线索详情、新建线索、添加跟进、创建预约、预约排班、公海、统计看板、修改密码、系统设置、404。设置页分别检查线索提醒、渠道接入、账号和业务规则。

## 已处理问题

| 问题 | 改进 |
| --- | --- |
| 成交状态覆盖来源列 | 进度区域允许在单元格内换行，标签限制最大宽度；历史记录显示“已成交”并在下一行说明“付款待确认” |
| 已结束记录仍显示邀约阶段或待回访 | 成交、无效、关闭记录统一显示“已结束”，不再显示过期回访提示；列表加入无效线索筛选 |
| 列表请求失败后没有稳定的恢复入口 | 显示可重试错误面板，保留筛选，暂停手机端自动加载，避免不断请求 |
| 详情加载失败时永久转圈 | 显示错误原因与重试；预约信息未成功更新时禁止新建预约 |
| 加载线索失败后仍允许填写跟进或预约 | 等上下文加载成功后显示表单，失败可重试 |
| 新建线索没有就地反馈联系方式缺失 | 电话和微信至少一项校验；创建失败时保留填写内容并显示错误 |
| 预约结束时间、人数校验不足 | 结束时间必须晚于开始；人数必须是正整数，错误显示在字段旁 |
| 弹窗键盘操作不统一 | 筛选、保存视图及五类预约弹窗接入焦点管理；提交期间防止重复操作及关闭预约弹窗 |
| 排班冲突请求可能先后错序 | 忽略旧请求；检查期间或检查失败时禁止安排，失败可单独重试 |
| 设置读取失败会暴露默认值 | 读取失败显示重试；通知、规则加载失败时隐藏可编辑配置并拦截保存；用户搜索忽略过时响应 |
| 登录与密码修改错误只短暂提示 | 持续显示错误，保留输入，阻止重复提交；登录回跳只接受本站路径 |
| 星级、开关缺少可访问名称 | 只读星级提供完整文字；可编辑星级支持原生单选键盘操作；开关补充名称 |
| 平板详情过密、手机日期被压缩 | 平板详情资料改为两列，操作区换行；手机日期导航独立布局以显示完整日期 |
| 页面层级与辅助文字不足 | 补全手机新建、跟进、统计页标题；提高状态和设置说明对比度；简化登录、密码页阴影与背景 |

## 验证方法

- 全页面 Chrome 检查：320、375、768、1440 像素；检查页面横向边界及 WCAG A/AA 自动规则。
- 成交标签专项：320、375、1024、1280、1440、1920 像素，覆盖历史付款未知、部分付款、全款、退款，以及长中文姓名/来源。
- 异常恢复：模拟列表、详情、跟进、预约读取失败，检查重试、筛选保持、无自动重试循环和表单保护。
- 键盘与表单：星级方向键、预约字段错误；已有纠错回归覆盖弹窗焦点、版本冲突及输入保留。
- 原有视觉、响应式和真实 API 纠错回归继续保留。

自动检查不能证明不存在所有交互问题；生产账号的具体数据、外部平台通知及多用户并发场景仍需结合实际使用观察。测试使用隔离数据，未修改线上业务记录。
