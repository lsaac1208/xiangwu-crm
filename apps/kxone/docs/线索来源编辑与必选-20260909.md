# 线索来源编辑与必选下拉（2026-09-09）

## 使用方式

- 已有线索：进入线索详情 → 编辑资料 → 来源渠道 → 选择来源 → 保存资料。原先未填写来源的线索也可补填。
- 手动新增：来源渠道为必填下拉，不默认替用户选择；未选时在字段下方提示“请选择来源渠道”，后端也校验必填与有效选项。
- 来源更换沿用客户资料编辑权限与版本冲突检查，写入操作记录；不改变线索当前业务状态、负责人或业务版本。
- 历史来源不在新选项中时显示“原有来源”，编辑其他资料可保留；不批量覆盖旧数据。已有来源不可清空。
- 改动使用现有 source_channel 字段，无数据库迁移；外部广告接入不受手动录入选项限制。
