## 模块职责

### Domain 层（纯函数，可独立测试）

**lead/state_machine.go**：
- 状态转换规则（DSL 化）
- 领取、分配、转派的前置条件校验
- 零外部依赖，100% 可测试

**card/lifecycle.go**：
- 卡片 response_code 生命周期管理
- 判断是否需要更新 vs 重发
- 重试时间计算（指数退避）
- 卡片内容构造（根据场景）

### Adapter 层（接口抽象）

定义外部系统接口，具体实现后续补充：
- `repo/interface.go`：数据库操作（GORM 实现）
- `cache/interface.go`：Redis 操作（go-redis 实现）
- `wecom/interface.go`：企业微信 API（手动封装）

### UseCase 层（业务编排）

**assign_lead.go**：主管分配线索
1. 校验前置条件（调用 domain 层）
2. 更新 CRM 状态（事务边界）
3. 记录分配日志
4. 异步更新主管卡片
5. 异步发送销售卡片

**claim_lead.go**：销售领取线索
1. Redis 幂等键（快速拒绝）
2. 校验前置条件（调用 domain 层）
3. 原子性领取（数据库乐观锁）
4. 异步更新双方卡片

### 关键设计点

**幂等保障**：
- 第一层：Redis SetNX（1 分钟内重复请求直接返回）
- 第二层：数据库乐观锁（最终保证原子性）

**状态分离**：
- CRM 状态（leads 表）：必须成功，事务保证
- 卡片状态（wecom_card_tasks 表）：异步更新，失败不回滚

**重试策略**：
- 卡片更新失败：10s、30s、60s 指数退避
- 3 次仍失败：重新发送新卡片

## 环境准备

### 1. 安装 Go

**macOS**：
```bash
brew install go
```

**验证安装**：
```bash
go version  # 应显示 go1.21 或更高版本
```

### 2. 初始化项目

```bash
cd /path/to/project

# 下载依赖
go mod download

# 运行测试（验证 domain 层纯函数）
go test ./internal/domain/...

# 启动服务（当前只有健康检查接口）
make dev
```

### 3. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 填写实际配置
```
