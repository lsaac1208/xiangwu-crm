# 主管之间分配与转派线索（2026-09-08）

## 用户操作

- 在邀约阶段线索详情点击“分配线索”或“转派线索”，在“选择邀约师或主管”中选择另一位启用的主管，再确认。
- 列表勾选多条线索后，可在“批量操作目标人员”中选择标有“主管”的人员，执行批量分配或批量转派。
- 接收主管可领取并继续跟进，也可以继续分配、转派；选择自己仍沿用原来的“由我负责”操作。

本次的“转发”沿用 CRM 的转派业务，不复制线索。原客户资料、创建人和跟进历史保留，操作记录保留实际分配人、接收人和备注。

## 修复内容

1. 解除“主管只能分配给自己”的旧目标限制，前后端均允许主管选择其他启用主管。
2. 单条和批量交接都同步更新所属主管和待领取人员，接收方能在正确权限范围内继续处理。
3. 支持待领取、已领取和跟进中的邀约线索转派；清除原持有人、领取时间和旧回访到期时间，等待新负责人领取。
4. 目标人员查询使用同一事务的仓储，避免 SQLite 单连接下嵌套使用连接。
5. 兼容生产环境未启用旧卡片仓储的配置，避免转派保存后因空卡片仓储报错。
6. 邀约转派接口保留阶段边界，谈单阶段使用原有谈单师转交流程；已成交等终态继续禁止转派。

未改变角色体系、客户数据结构、数据库迁移、渠道或通知配置。保留工作区此前已有改动，未提交 Git。
